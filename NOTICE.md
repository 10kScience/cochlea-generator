# Data and asset notice

This repository contains procedurally generated meshes and measurement-driven
software developed for 10k Science.

The original MorphoSource and other anatomical scan meshes used as visual
references during development are not included. Reference media identifiers in
the presets are provided solely for provenance. Retrieve source scans from
their repositories under the terms attached to each source record.

The generated cochleas are comparative scientific visualizations, not medical
or diagnostic models. Several shape properties that are not directly measured
in the cited datasets are inferred by one shared procedural model and are
documented in the repository methodology.
